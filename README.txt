ARB-BOT v2 — быстрый старт
==========================

1. Установи Node.js 18+  →  https://nodejs.org  (кнопка LTS)
2. Распакуй этот архив в папку
3. Открой терминал в папке:
   Windows: в проводнике в адресной строке набери  cmd  и Enter
   Mac: правый клик по папке → «Открыть в Терминале»
4. Выполни две команды:

   npm install ccxt
   node arb-bot.js

Готово. Бот работает в PAPER-режиме (демо-счёт $1000):
реальные цены, стаканы и funding с 8 бирж, сделки симулируются.
API-ключи для демо НЕ нужны.

Что увидишь в консоли:
  ▶ PAPER вход ...        — открыл спред-сделку
  ⏹ PAPER закрыл ...      — закрыл, PnL и баланс
  ▶ PAPER FUNDING вход ... — открыл funding-позицию
  💰 FUNDING выплата ...   — начисление каждые 8 часов
  · кандидат ... не прошёл стакан — фантомный спред, отсеян
  ♥ ...                    — пульс каждые 10 минут

Статистика копится в paper-log.json (баланс, винрейт, все сделки).

Остановка: Ctrl+C, или создай пустой файл STOP рядом с ботом.
Компьютер не должен засыпать, пока бот работает.

Настройки — в начале arb-bot.js, блок CFG (монеты, биржи,
пороги, комиссии, размеры). Дефолты разумные, для демо не трогай.

LIVE-режим (реальные деньги) — ТОЛЬКО после недели демо в плюсе:
ключи в VENUES (вывод ВЫКЛ, IP-whitelist ВКЛ), MODE:"live",
запуск: ARM_LIVE=yes node arb-bot.js

Не финансовый совет. Риск на пользователе.
